# TOOFLESS V4 🦎🦷

**No teeth. No utility. Just TOOF.**

This version adds:

- transparent dancing TOOFLESS mascot
- seamless CSS desert hero background
- floating tooth animation
- pause/play dance button
- mobile-first responsive layout
- high-contrast hero text
- lore, roadmap, quote and disclaimer sections

## Upload to GitHub

Replace/add these files in the repository root:

- `index.html`
- `style-v4.css`
- `script-v4.js`
- `toofless-dance.png`

GitHub Pages can keep deploying from `main` and `/ (root)`.
